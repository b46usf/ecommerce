# Security policy

Jangan membuka issue publik untuk kerentanan atau kredensial yang bocor. Gunakan **Security > Advisories > New draft security advisory** pada repository GitHub agar laporan dan diskusi tetap privat.

Sertakan langkah reproduksi, dampak, versi atau commit yang terdampak, dan bukti secukupnya tanpa menyertakan data pribadi pengguna. Jangan menguji terhadap data atau akun milik orang lain.

Jika sebuah secret pernah masuk Git, cabut atau rotasi secret tersebut terlebih dahulu. Menghapus file dari commit terbaru tidak membatalkan secret yang sudah tersimpan di riwayat Git.
